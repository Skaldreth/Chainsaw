# Kortkommandon

> **Som i vardagen:** kortkommandon är som att kunna vägen utantill i stället för att läsa skyltarna. I början läser du
> skyltarna, och tipsen visar tangenten bredvid varje knapp. Efter ett tag går händerna själva.

Varje knapp i Chainsaw har sitt kortkommando i tipset när du håller pekaren över den. Här står de samlade.

## Överallt

| Tangent | Gör |
| --- | --- |
| Ctrl+K eller Ctrl+F | Kommandoraden, se [Kommandoraden och länkar](kommandoraden.md) |
| Ctrl+N | Nytt ärende |
| Ctrl+O | Ärendeväljaren |
| Ctrl+W | Spara och stäng ärendet |
| Ctrl+L | Lås Chainsaw |
| Ctrl+1 | Grafen |
| Ctrl+6 | Bevakning |
| F1 | Guiden |
| Ctrl+, | Inställningar |
| Esc | Stänger det som är öppet |

## I grafen

| Tangent | Gör |
| --- | --- |
| E | Expandera den valda noden |
| L | Etikett |
| B | Bevaka |
| U | Bryt upp ett kluster |
| K | Annan kedja |
| R | Fråga Chainabuse om rapporter |
| Ctrl+C | Kopiera adressen |
| Z | Egen yta runt de valda aktörerna |
| N | Ny kommentar, knuten till den valda noden, se [Kommentarer i grafen](kommentarer.md) |
| Dubbelklick på tom yta | Ny kommentar där |
| Delete | Släng det valda i soptunnan (en vald kommentar tas bort), se [Soptunnan](soptunnan.md) |
| Ctrl+Z | Ångra den senaste slängningen |
| Ctrl+J | Förslag, se [Kontroller och förslag](kontroller-och-forslag.md) |
| Shift+F1 | Guiden vid spårningsmetoden, som högerklick på metoden, se [Spårningsmetoder](sparningsmetoder.md) |
| F | Passa in hela grafen |
| + och − | Zooma; mushjulet gör samma sak |
| Ctrl+klick | Välj flera |
| Dra en ruta på tom yta | Välj allt rutan rör; med Shift läggs det till, med Ctrl vänds det, Esc avbryter |
| Höger- eller mittknappen | Panorera |
| Ctrl+V | Klistra in en startpunkt på den tomma grafen |
| Esc | Stäng formuläret, lämna en vald tid, stäng inspektören |

I formulären sparar **Enter** och **Esc** avbryter. Skälet är alltid frivilligt.

## I valvyn och högen

| Tangent | Gör |
| --- | --- |
| Klick, Shift-klick | Välj en, eller ett intervall |
| L | Välj med en ring som du drar |
| Enter | Plocka ut de valda |
| Esc | Stäng, eller avbryt läsningen av historiken |

Se [Det som hölls tillbaka, högen och valvyn](det-som-holls-tillbaka.md).

## I förslagen

| Tangent | Gör |
| --- | --- |
| Enter | Godkänn |
| X | Avfärda (eller avfärda resten) |
| J och K | Stega mellan förslagen (J är *Senare*) |

## I inställningarna

| Tangent | Gör |
| --- | --- |
| Alt+↑ och Alt+↓ | Flytta en endpoint i läget Prioriterad |

Se också [Röra sig i grafen](rora-sig-i-grafen.md).
